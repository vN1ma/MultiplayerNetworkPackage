# Custom Voice Modifier

Beispiel fuer ein eigenes Klangmodul, ohne Paketcode zu aendern.

`RadioModifier` simuliert ein Funkgeraet: feste Lautstaerke, kein Raumklang, blecherner
Frequenzgang. Es laeuft mit `VoiceModifierOrder.Transmission` und hebt deshalb Distanz,
Waende und Tueren bewusst auf.

## Verwendung

1. Sample importieren.
2. Rechtsklick im Project-Fenster → `Create > Earshot > Samples > Radio`.
3. Das entstandene Asset in das `VoiceProfile` ziehen.

Zum Abschalten das Haekchen am Asset oder das Asset aus dem Profil nehmen.

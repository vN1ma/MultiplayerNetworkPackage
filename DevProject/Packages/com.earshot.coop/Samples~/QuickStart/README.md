# Quick Start

Zwei Raeume, eine Wand, eine Tuer. Die kleinste Szene, in der man hoert, wie Earshot
Stimmen daempft.

## Einrichtung

1. `Tools > Earshot > Setup` ausfuehren und ein Player-Prefab zuweisen.
2. Leere Szene anlegen.
3. Leeres GameObject erstellen, Komponente `Earshot/Samples/Quick Start Layout` hinzufuegen.
4. Im Inspector der Komponente rechtsklicken → **Build Quick Start Layout**.
5. Szene speichern.
6. Play druecken. Im Overlay zuerst **Lokal starten** — kein Unity-Account noetig.
   Internet-Host und Join-Code erst, wenn Services verknuepft sind.

Ein Spieler startet links, der andere rechts. Die Tuer in der Mitte mit **E** benutzen
(Interactor muss dazu auf dem Player-Prefab liegen). Hinter der geschlossenen Tuer klingt
die Stimme dumpf; offen klingt sie klar.

`F1` blendet das Join-Menue, `F3` das Voice-Debug-Overlay.
